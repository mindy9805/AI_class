# 結帳系統 → Google Sheet（Google Apps Script）部署說明

## 運作方式
```
網站結帳表單 ──POST(JSON)──▶ GAS Web App ──▶ ① 驗證並用伺服器價格表重算金額
                                           ├─▶ ② 寫入「訂單」工作表（編號由伺服器產生）
                                           ├─▶ ③ 寄「訂單確認信」給客人
                                           └─▶ ④ 寄「新訂單通知」給店家
每天 22:00（時間驅動觸發器）──▶ 寄「每日營收摘要」給店家
```

## 部署步驟（約 10 分鐘）
1. 建立一份新的 **Google 試算表**（名稱自訂，例如「煎心鍋貼訂單」）。
2. 選單 **擴充功能 → Apps Script**，把預設的 `Code.gs` 內容整份換成本資料夾的 `Code.gs`。
3. 修改檔案最上方 `CONFIG.SHOP_EMAIL`（店家收件信箱），其他設定視需要調整。
4. 上方函式選單選 **`setup`** → 按「執行」。第一次會要求授權（試算表、寄信、觸發器），請允許。
   完成後試算表會出現「訂單」工作表（標題列、狀態下拉選單、依狀態上色），並建立每日摘要觸發器。
5. **部署 → 新增部署作業 → 類型：網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製 **網頁應用程式網址**（結尾是 `/exec`）。
6. 打開 `index.html`，找到 `const GAS_URL = '';`，貼上網址後提交推送。
7. 驗證：瀏覽器開啟該網址應看到 `{"ok":true,...}`；網站下一筆測試訂單應出現在試算表並收到兩封信。

> 之後只要修改 `Code.gs`，必須 **部署 → 管理部署作業 → 編輯 → 版本：新版本** 才會生效，網址不變。

## 試算表欄位
訂單編號｜建立時間｜狀態｜姓名｜手機｜Email｜取餐方式｜門市／地址｜備註｜商品明細｜件數｜小計｜運費｜總額｜預計時間｜（隱藏）商品JSON

- **狀態**：待處理／製作中／已完成／已取消（下拉選單，整列依狀態上色）。
- 「商品JSON」欄位供每日摘要統計熱銷品，請勿刪除。

## 防護機制
- 金額與商品由伺服器端價格表重算，前端送來的價格一律不採用。
- 欄位驗證與長度限制；商品只接受價格表內的代號與合理數量。
- 蜜罐欄位＋填表時間過短即拒絕；同手機 20 秒內不可連送。
- `reqId` 防重複：網路不穩重送同一筆不會重複下單。
- 訂單編號在鎖定（LockService）中產生，避免同時下單編號重複。

## 修改商品或價格時
網站的 `MENU` / `GIFTS` 與 `Code.gs` 的 `PRICES` 要**同步修改**（商品代號相同）。價格以 `Code.gs` 為準。

## 注意事項
- 一般 Google 帳號 `MailApp` 每日約 100 封（Workspace 約 1,500 封）。每筆訂單寄 2 封，量大請改用 Workspace 帳號。
- 信件由你的 Google 帳號寄出；客人回信會回到該帳號。
- 網址公開，任何人都能 POST，防護僅為基本等級；若遭濫用，可在部署管理中停用或重新部署取得新網址。
- 若想進一步管理（例如狀態變更時通知客人、庫存），可再於 `Code.gs` 加 `onEdit` 觸發器。
