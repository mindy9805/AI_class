\# Role & Goal 你是一位資深的 Front-End Developer 與 UI/UX 設計師。請為一家「極簡現代風鍋貼專賣店」製作一個完整的單頁式（Single-Page Application / Single HTML）品牌官網。 \# Technical Constraints & Tech Stack 1\. 必須是單一 HTML 檔案（Single-file HTML），所有 CSS (Tailwind CSS CDN) 與 JavaScript (Alpine.js 或 Vanilla JS) 直接內嵌在檔案中。 2\. 樣式庫：請引入 Tailwind CSS CDN (\)。 3\. 圖標庫：請引入 Lucide Icons CDN 或 FontAwesome CDN。 4\. 圖片素材：使用 Unsplash 的美食與餐廳相關 高解析度 Placeholder 圖片。 5\. 響應式設計 (RWD)：必須完美支援 Mobile (375px)、Tablet (768px) 與 Desktop (1280px+)。 6\. 視覺風格：溫暖質感、現代極簡風（主色調：深木質棕/暖橘/米白，字體採用優雅的無襯線體與典雅標題）。 \# Page Architecture & Sections 1\. \*\*Header / Navigation (頂部導覽列)\*\*    - Logo（品牌名稱與標誌）    - 平滑滾動導覽選單 (Smooth Scroll)：品牌故事、熱門餐點、線上點餐、冷凍禮盒、門市據點、聯絡我們    - 右側固定：購物車圖示 (含數量 Badge) 與「立即點餐」CTA 按鈕 2\. \*\*Hero Section (主視覺區)\*\*    - 高質感品牌形象大圖/背景    - 品牌 Slogan（如：「金黃酥脆，傳承手藝的極致美味」）    - 雙 CTA 按鈕：「線上點餐」與「探索門市」 3\. \*\*Brand Story (品牌介紹)\*\*    - 品牌理念簡介、食材堅持（台灣在地豬肉、每日現包、黃金煎脆比例）    - 數據展示區（例：每日賣出 10,000+ 顆、100% 現點現煎、30 年老店技術） 4\. \*\*Featured Menu / Online Ordering (線上點餐與菜單區)\*\*    - 分類 Tab 切換：招牌鍋貼、精選水餃、湯品/飲料、經典小菜    - 產品卡片包含：圖片、品名、簡介、價格、辣度/標籤（如：爆汁、人氣）、[加入購物車] 按鈕 5\. \*\*Gift Boxes (冷凍禮盒專區)\*\*    - 介紹家庭組/節慶伴手禮盒（如：招牌招財鍋貼禮盒 50 入）    - 特色說明（液態氮急速冷凍、在家 8 分鐘還原門市美味）    - [直接購買/加入購物車] 按鈕 6\. \*\*Locations & Hours (門市據點與營業資訊)\*\*    - 多門市切換卡片（旗艦店、信義店等）    - 提供：地址、電話、營業時間、外送合作平台標誌 (UberEats/Foodpanda)、Google Maps 擬真嵌入 UI 7\. \*\*Footer (頁尾)\*\*    - 社群媒體連結 (IG, FB, Line)、版權宣告、隱私權政策連結、電子報訂閱表單 \# Interactive Requirements (JS Functionality) 1\. \*\*互動式購物車 (Cart Drawer / Modal)\*\*    - 點擊「加入購物車」時，頂部購物車 Badge 數字增加，並跳出 Toast 通知。    - 側邊抽屜式購物車 (Cart Drawer)：可調整數量 (+/-)、刪除商品、計算小計與總金額。    - 模擬結帳流程：按下「前往結帳」可彈出訂單確認 Modal（包含內用/外帶/宅配選擇、聯絡資訊表單），提交後顯示「訂單已建立」成功畫面並清空購物車。 2\. \*\*篩選與切換 (Tab & Filter)\*\*    - 菜單分類切換流暢，免重新載入頁面。 3\. \*\*FAQ (常見問題)\*\*    - 使用 Accordion (手風琴效果) 展示點餐、保存方式與外送常見問題。 \# Output Deliverables \- 請提供\*\*單一且完整\*\*的 HTML 檔案程式碼，包含所有 CSS、JS 與 HTML 結構。 \- 程式碼需結構清晰，包含適當的 HTML5 語意化標籤 (\
